# IncluForge

IncluForge is an interactive accessibility workbench built with HTML, CSS and JavaScript. It provides a practical environment for exploring inclusive interface design and testing common web accessibility issues.

## Features

- Keyboard navigation with ARIA tabs, menus, disclosures and modal dialogs.
- Form validation with accessible error messages.
- Color contrast calculations based on WCAG luminance formulas.
- Text magnification, reflow and color-vision simulations.
- A remediation workshop demonstrating accessibility barriers and fixes.
- An accessibility audit checklist with report generation and printing.
- Day, night and high-contrast appearance modes.
- Responsive layout and visible keyboard focus indicators.

## Technologies

- HTML5
- CSS3
- JavaScript
- WAI-ARIA
- WCAG 2.1 accessibility guidelines

## Running the Project

Open `index.html` in a modern web browser. No build tools or package installation are required.

The project is intended for learning and demonstration. Its simulations do not replace testing with real assistive technologies or a full accessibility audit.
